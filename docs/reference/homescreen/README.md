# Visuelle Referenz: Homescreen 2026-08-15

Diese Dateien sind die unveränderten Hi-fi-Referenzen aus
`Homescreen Design neu entwerfen.zip`. Sie dokumentieren den visuellen Ausgangsvertrag für
den Architektur-Refactor. Die HTML-Dateien im ursprünglichen Handoff bleiben die Quelle für
Maße und Interaktionen; diese PNGs dienen späteren Screenshot- und Golden-Vergleichen.

| Datei | Zustand |
| --- | --- |
| `01-heute-voller-tag.png` | voller Heute-Screen am Tag |
| `02-schritt-abgehakt.png` | einzelner erledigter Schritt |
| `03-nach-spaeter.png` | Reihenfolge nach „später“ |
| `04-nach-rest-erledigen.png` | Fokuswechsel nach Abschluss |
| `05-heute-wenig-los-abend.png` | reduzierter Abendzustand |
| `06-heute-leer-nacht.png` | leerer Nachtzustand |
| `07-widget-2x2.png` | kleines Widget |
| `08-widget-4x2.png` | breites Widget |
| `09-widget-4x4-nacht.png` | großes Nacht-Widget |
| `10-widget-3x4-abend.png` | hohes Abend-Widget |

Die Referenzen sind keine Behauptung, dass der aktuelle Android-Stand bereits pixelgenau
entspricht. Abweichungen werden in späteren Phasen mit gerenderten Golden-Screenshots
nachvollziehbar gemacht.
