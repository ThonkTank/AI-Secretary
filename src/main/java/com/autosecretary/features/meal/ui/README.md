# Meal UI – manuelle Prüfschritte

1. App starten und in der Bottom-Navigation den Tab **Mahlzeiten** öffnen.
2. Unter **Rezepte** ein Rezept auswählen (bei leerem Bestand wird automatisch ein Demo-Rezept angelegt).
3. Unter **Wochenplan** auf **+ Rezept planen** tippen und Datum, MealType und Portionen erfassen.
4. Den neuen Plan-Eintrag über **Erledigt** als erledigt markieren und erneut auf **Offen** zurücksetzen.
5. Unter **Vorrat & Einkauf** über **+ Bedarf in Einkauf** einen Einkaufseintrag erzeugen.
6. Unter **Vorrat & Einkauf** über **+ Vorratseintrag** einen Pantry-Eintrag mit Haltbarkeitstagen anlegen.
7. Prüfen, dass beim Pantry-Eintrag die Ablauf-Info korrekt auf Basis der ShelfLife-Berechnung angezeigt wird.
